Python Mini Projects

This repository contains beginner-friendly Python programs that I built while learning Python fundamentals such as loops, lists, sets, conditions, and the random module.
Projects Included

1. Rock Paper Scissors

A simple game where the user plays Rock, Paper, Scissors against the computer.
The computer randomly chooses an option and the program decides the winner.

2. Word Guess Game

A word guessing game where the computer selects a random word and the user tries to guess it letter by letter until the word is revealed.

3. Random Password Generator

A program that generates a random password based on the length provided by the user using letters, numbers, and symbols.

Concepts Used:
- Python Lists
- Loops
- Conditional Statements
- User Input
- Random Module
